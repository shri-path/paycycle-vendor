PayCycle Vendor is a daily operating system for recurring local vendors (milk, newspaper, bread) in tier 2-3 Indian cities.

**Why:** Target users are non-tech-literate, use low-end Android devices (2GB RAM), and have spotty internet.

**How to apply:**
- UX must be WhatsApp-inspired: tap-first, minimal typing, large touch targets, chat-style interactions
- Every feature must work offline-first (WatermelonDB local writes, background sync)
- All text must be translatable (9 languages: en, hi, ta, te, mr, bn, kn, ml, gu via i18n-js)
- Design uses Trust Green theme (#075E54 primary)
